# yiA Web UI 原型生成提示词 · 空间玻璃融合版（complex.md）

> 本文档 = `webUI_prompt.md`（yiA M6 功能规格）+ `eg_ui.md`（参考图 visionOS 空间玻璃风格）的融合版。
> 用途：把"投喂给工具的提示词"以下整段投喂给原型/AI 生成工具（v0、Lovable、Motiff、Figma AI、即时设计 AI 等），生成 yiA M6 Web 界面的高保真原型。功能、信息架构、示例数据、边界状态全部齐备，视觉以参考图的空间玻璃为准，工具无需追问即可产出。

## 投喂给工具的提示词（从此处开始复制）

### 产品背景

yiA 是一个部署在用户自己电脑上的"第二大脑"个人助理：通过对话存储信息、按需召回知识、定时提醒推送到微信。现在要为它设计 Web 管理界面（桌面优先，1366px 以上），供用户在浏览器中使用全部能力。

**视觉总基调：悬浮在书房里的"空间玻璃"界面（Apple visionOS 风格）。** 浏览器窗口本身呈现为一块/多块漂浮的毛玻璃，背景是暖色调、景深虚化的真实书房环境（木质书架、暖光、绿植，呼应"私人档案馆 / 个人书房"气质）。所有界面结构靠**不同厚度的半透明玻璃 + 留白**区分，而不是色块、边框或传统后台框架。安静、通透、轻盈、内容优先；不要 SaaS 后台模板脸，也不要蓝紫渐变与科技荧光色。

### 视觉与材质规范（全站统一，逐页都要遵守）

- **环境背景**：全屏固定一张暖色调、明显景深虚化的书房/室内环境影像（可用 CSS 暖木色 + 柔焦渐变近似：如 `radial-gradient` 叠加 `#8a7a66 / #6d6253 / #4a443c` 的暖灰棕系），上面所有玻璃漂浮；背景不随页面滚动。
- **玻璃材质（核心）**：
  - 主窗口：`background: rgba(255,255,255,0.12~0.16)` + `backdrop-filter: blur(40px) saturate(170%)`，圆角 32px，1px 镜面边缘 `rgba(255,255,255,0.20)`，内顶高光 `inset 0 1px 1px rgba(255,255,255,0.28)`，柔和大投影 `0 24px 64px rgba(0,0,0,0.25)`。
  - 次级玻璃（标签轨、小药丸、输入框、行内徽章）：填充 `rgba(255,255,255,0.10~0.14)`，blur(24px)，圆角 24–28px（按钮用 999px 全圆角）。
  - 玻璃上一律不要重描边；层级靠透明度、模糊半径、投影区分。
- **文字（玻璃上的白，透明度三级）**：主文字 `rgba(255,255,255,0.96)`、次要 `rgba(255,255,255,0.72)`、辅助/元数据 `rgba(255,255,255,0.55)`。发丝分割线 `rgba(255,255,255,0.16)`。
- **强调色（克制使用，全站仅两处语义色）**：保留原规格的朱砂/砖红作为强调色，在玻璃上用半透明暖红呈现（如 `#E26252` 实色用于枢纽角标描边、危险操作文字；徽粉底 `rgba(226,98,82,0.16)`）；苔绿成功色（`#34C759`，玻璃底 `rgba(52,199,89,0.16)`）用于状态点、正常状态、微信渠道徽章。
- **按钮规则**：每个视图最多一个**实心深色主按钮**（`rgba(28,28,30,0.92)` 近黑胶囊、白字、圆角 999、padding 12×28，对应参考图的 "Request Price"）；其余操作全部为**玻璃药丸按钮**（线性图标 + 文字，hover 填充透明度 0.14→0.22）；危险操作为玻璃药丸 + 暖红字，二次确认弹层中才出现实心暖红按钮。
- **字体**：`-apple-system, "SF Pro Display", Inter, "PingFang SC", sans-serif`；页面大标题用半粗体（参考详情页可用大写字距拉开的排法，但中文不强行大写）；**所有 id、时间戳、元数据一律等宽字体**（`"SF Mono", "JetBrains Mono", ui-monospace, monospace`），保留档案编号感——这是 yiA 的识别细节。
- **图标**：全站统一 1.5–2px 细线性图标（SF Symbols 风格），默认次级白色，不使用实心彩色图标。
- **窗口动效**：窗口/抽屉出现用 300ms `cubic-bezier(0.22,1,0.36,1)`，轻微缩放 0.96→1 + 淡入；hover 只改玻璃透明度；不要弹跳过头、不要扫光特效。
- **滚动条**：自定义为窗口右缘外侧漂浮的白色细胶囊（宽 6px、全圆角、半透明白），不要默认灰色滚动条。
- 玻璃需要 `-webkit-backdrop-filter` 回退；若环境不支持 backdrop-filter，退化为 `rgba(40,36,32,0.72)` 的深色磨砂实底，保证白字可读。

### 全局结构

- **环境层之上不设传统头部横条与铺底色侧栏**。布局为：左侧一条**与主窗口分离、独立漂浮的竖向玻璃标签轨** + 右侧一块主内容玻璃窗口（窗口距屏幕边缘至少 48px，居中偏上，让环境充分露出）。
- 悬浮标签轨（宽约 72px，竖向玻璃胶囊）：顶部品牌符号「yiA」（等宽或半粗小字）；其下 4 个主导航线性图标——**对话 / 记忆图谱 / 提醒 / 微信**；当前页图标背后有乳白色圆形高亮托底（44px 圆，`rgba(255,255,255,0.28)`）。标签轨底部放系统状态：一个小玻璃圆钮，绿/灰小圆点表示调度守护与网关在线；hover/点击展开小玻璃浮层，等宽小字列出"调度守护在线 · 网关在线 · 记忆 N 条 · 待发提醒 N"，异常项用暖红点。
- 主窗口：内边距 28–32px；顶部为页标题（28px 半粗白）+ 副标题（13px 等宽、三级白），标题下方可加一条通长发丝分割线；下方为页面内容。
- 全局交互：所有列表空态/加载态/错误态都要有（样式见文末边界状态清单）；危险操作（删除/登出/换绑）需二次确认，确认弹层为居中漂浮的小玻璃窗口（非浏览器原生 confirm）。
- 所有可滚动区域内容只在玻璃窗口内部滚动，窗口本身位置固定。

### 页面一：对话（默认首页）

- 一块主玻璃窗口承载聊天信息流。用户消息靠右：深灰实体胶囊气泡（`rgba(28,28,30,0.86)`、白字、圆角 20px）；助手回复靠左：**无气泡底色**，直接以白色正文落在玻璃上（仅底部用发丝线或留白与下一条分隔），发送者与时间用 12px 等宽三级白小字。
- 助手回复中的**知识引用**做成可点击的玻璃小芯片：等宽小字「来源 20260914043333-vnpddz」，玻璃药丸底 + 1px 镜面边；点击在主窗旁浮出一块小号玻璃卡（沿用参考图"详情双窗并排"模式），显示该记忆条目摘要。
- 信息流顶部是可折叠的「ContextPack 已注入」玻璃条：比主窗更薄的一条内嵌玻璃，左侧小档案图标 + 等宽小字标题，右侧 chevron；展开后用等宽小字分栏列出 当前时间 / 用户画像摘要 / 相关记忆 id 列表 / 待办提醒——做出"系统在思考前先翻档案"的感觉。
- 底部固定一条玻璃输入条（圆角 999 的玻璃胶囊内接输入区）：文字输入 + 右侧实心深色圆形/胶囊发送按钮；Enter 发送。
- 示例数据：用户"记住：周五要交开题报告初稿"→ 助手"已存好 ✅ 条目 20260914135201-k7x9mf，已自动关联「论文进度」2 条旧记忆"（条目中的 id 用等宽、苔绿色点缀）。
- 空态：玻璃中央安静排 3 个玻璃药丸快捷提问示例（"记住…"/"我之前说过…"/"提醒我…"），点击直接填入输入框。

### 页面二：记忆图谱（L2 知识库 + 知识图谱，双岛合并页）

- 本页**不再是单一主窗口**，而是仿照参考图格局，在标签轨右侧并排漂浮**两块独立玻璃岛**（左岛略大、右岛略窄，间距 24px，两岛等高、顶部对齐，各自具备完整的镜面边缘与柔和投影；岛距屏幕边缘至少 48px）。页标题"记忆图谱"+ 等宽副标题可放在左岛顶部，不另设横跨两岛的标题栏。

**左岛 · 档案文件（约占 55% 宽）**

- 岛顶一行：玻璃胶囊搜索框（放大镜线性图标 + 占位文案"检索…（BM25）"，等宽占位字）+ 右侧实时计数"N 条目"（等宽三级白）。
- 岛身为可滚动的**文件列表**：每个记忆条目是一份"档案文件"——薄玻璃圆角行（填充 `rgba(255,255,255,0.08)`、blur(20px)、圆角 18px、镜面边，行间 12px 间隙），允许保留 ≤0.3° 的随机微倾角（hover 回正并轻微上浮）。每行：标题（半粗白 17px）、摘要 1–2 行（二级白 14px）、元数据行（12px 等宽三级白：条目 id / 双向链接数 ↔N / 标签·标签）。
- 关联数 ≥3 的文件行右侧有"枢纽"角标：朱砂描边玻璃小标签（文字暖红、底 `rgba(226,98,82,0.16)`、圆角 999）。
- 行 hover 玻璃泛白；**与右岛联动**：hover 文件行时，右岛图谱中对应节点高亮放大、相关边提亮，其余节点降透明度。

**右岛 · 图谱（约占 45% 宽）**

- 岛身为全幅图谱画布（内容铺满岛身，圆角随岛）：节点=记忆条目，边=双向链接。边为 `rgba(255,255,255,0.25)` 1px 细线；普通节点=白色小圆（5–6px，`rgba(255,255,255,0.85)`）；枢纽节点（链接≥3）=朱砂色大圆（9px，`#E26252`，带一圈同色 30% 光晕）。节点可拖拽、画布可平移。
- hover 节点浮出小玻璃卡：标题（半粗）+ id（等宽三级白）+ 链接数；同时左岛对应文件行高亮并自动滚动到可视区。
- 左下角玻璃图例小卡（薄玻璃、圆角 18）：小白圆=记忆条目，朱砂大圆=核心枢纽。
- 右上角降级开关：一枚玻璃药丸开关"图谱不可用时显示关联列表"；关闭时右岛替换为关联条目玻璃行列表（体现工程降级思维）。

**聚焦阅读层（核心交互，点击文件后出现）**

- 触发：点击左岛任一文件行，或点击右岛任一图谱节点。
- 此时整个环境进入**四周模糊压暗态**：书房背景、双岛、标签轨全部保留在原位，但被一层遮罩覆盖——`background: rgba(20,18,16,0.45)` + `backdrop-filter: blur(24px) saturate(120%)`，遮罩 250ms 淡入。
- 屏幕正中浮出一块较宽的主玻璃聚焦窗（约 760px 宽、圆角 32，完整厚玻璃材质），以 300ms `cubic-bezier(0.22,1,0.36,1)` 从 0.96 缩放淡入。窗内自上而下：
  - 顶部：文件标题（24px 半粗白）+ 下一行等宽 id（三级白）；右上角一枚圆形玻璃关闭钮（× 线性图标）。
  - frontmatter 原文块：`rgba(0,0,0,0.28)` 深色代码底 + 等宽字、圆角 16，内含 id/title/tags/links/created 的 yaml。
  - 正文全文：15px、行高 1.7、二级白，段落留白安静。
  - 底部操作行：「编辑」玻璃药丸；「删除」玻璃药丸 + 暖红字（点击再弹二次确认小窗：取消玻璃药丸 / 确认删除实心暖红胶囊）。
- 退出：点击遮罩空白处、按 Esc 或点关闭钮 → 聚焦窗缩小淡出、遮罩淡出，回到双岛视图；删除成功后同步从左岛列表与右岛图谱移除该节点。

**过滤与数据**

- 搜索为前端过滤：左岛过滤文件行，右岛同步将无关节点降至 15% 透明度（不销毁布局）；空结果显示"未检索到，换个关键词试试"+ 一枚重置搜索的玻璃药丸。
- 示例数据（至少 7 条，题材多样）：咖啡偏好（燕麦拿铁无糖）/ 论文开题待办 / 项目复盘（微信换绑事故）/ 模型知识（GLM 上下文规格）/ 徒步路线 / 开源检查清单 / 读书笔记。图谱节点与边基于这批数据的 links 构造，确保其中至少 2 个枢纽节点（如"论文开题待办""项目复盘"）。

### 页面三：提醒

- 主体：日程簿式**行列表**（表格式行，非卡片），行直接落在主窗玻璃上，行间用 `rgba(255,255,255,0.12)` 发丝线分隔，行高宽松（约 64px），行 hover 玻璃泛白（叠加 `rgba(255,255,255,0.06)`）。
- 每行：触发时间列（等宽字，日期 + 钟点两行，主白色）+ 内容列（15px 白色）+ 渠道徽章列（**微信=苔绿描边玻璃小徽章**，底 `rgba(52,199,89,0.14)`；TUI=灰白描边）+ 操作列（"完成/取消"为三级白文字链接，hover 变白）。
- 行排序按触发时间升序；已触发行整体置灰（文字透明度降到 0.4）、内容划线、操作变"删除"（暖红文字链接）。
- 顶部说明行（12px 等宽三级白）："按触发时间排序 · 唯一触发者=调度守护 · 错过自动补发"。
- 重复提醒的时间列在钟点下显示"重复"字样（等宽三级白），如"每天 09:30 / 重复"。
- 新建入口：窗口右上"新建提醒"——本页唯一的实心深色胶囊主按钮。点击弹出居中漂浮的小玻璃窗口：内容输入 + 自然语言时间输入（玻璃输入框，占位"如：明天早上八点"）+ 渠道选择（两枚玻璃分段药丸，选中态乳白托底）+ 取消（玻璃药丸）/保存（实心深钮）。
- 示例：明天 08:00 体检提醒（微信）/ 每天 09:30 站会（微信）/ 今天 12:39 E2E 验证（已触发，置灰划线）。

### 页面四：微信

- 主窗口内左右两块内嵌玻璃（圆角 24、间距 24）。
- 左块「通道状态」：键值对列表，键为三级白 13px，值为白色 14px 等宽——bot 账号（"运行中"用苔绿文字 + 6px 绿点）/ 发送账号绑定状态 / 推送目标（长 id 等宽截断，中间省略号）/ 配对白名单（N 人 · 待批 N，待批用暖红）/ 最近端到端送达时间（等宽）。行间发丝线分隔。
- 右块「扫码登录」：二维码占位框（220×220，玻璃底 + 四角定位标用暖红/白色细 L 形角标绘制，中间放线性手机图标），下方 13px 二级白说明"登录后账号自动绑定，旧账号自动登出"。
- 底部操作行：「发测试消息」为玻璃药丸（带发送线性图标）；「换绑微信」为玻璃药丸 + 暖红字，点击弹出居中二次确认小玻璃窗："将登出全部已登录账号并用新号扫码，继续？"，按钮为 取消（玻璃药丸）/ 确认换绑（实心暖红胶囊 `rgba(226,98,82,0.95)`）。
- 状态语义：所有正常值苔绿、异常值暖红、未知灰白。

### 边界状态清单（每页都要，样式统一）

- 加载中：玻璃内显示骨架屏（用 `rgba(255,255,255,0.10)` 圆角块 + 呼吸式透明度动画），或居中等宽三级白小字"读取 runtime/…"。
- 空：居中安静插画位（线性图标，三级白）+ 一句友好说明 + 一枚玻璃药丸引导动作。
- 错误：一块浅暖红底玻璃提示卡（`rgba(226,98,82,0.14)` + 暖红发丝边、圆角 20），**错误文本用等宽字原样展示，不做友好化吞错**（本产品理念：错误信息直接给用户看）。

### 交付要求

- 桌面优先单页应用：环境背景固定，左侧悬浮玻璃标签轨切换 4 个页面（对话 / 记忆图谱 / 提醒 / 微信），主窗口内容随切换以 300ms 淡入缩放过渡。
- 1366px 以上良好呈现；普通页面单窗最大宽度约 1200px，记忆图谱页为左 55% / 右 45% 双岛布局，再宽时整体居中并让环境背景露出更多。
- 中文界面，全部文案使用本规格给出的真实示例数据。
- 可交互：导航切换（含乳白圆托底移动）、记忆图谱双岛联动（文件行 ↔ 图谱节点 hover 互高亮）、搜索双向过滤、点击文件/节点弹出四周模糊的聚焦阅读层（Esc / 点遮罩 / 关闭钮退出，含删除二次确认）、新建与确认弹层、行内完成/取消、图谱节点拖拽与降级开关（如工具支持）。
- 视觉必须达到参考图水准：毛玻璃通透有镜面边缘和柔和投影、窗口漂浮、白色文字透明度分级、每视图仅一个实心深色主按钮、细线性图标。
- 不要：登录页、多租户、仪表盘图表、通知红点、新手引导；不要传统网页头部横条/铺底色侧栏/卡片粗描边/蓝紫渐变/荧光色/默认浏览器滚动条。

## 融合对照（供理解，不必投喂）

| 原 webUI_prompt 规格 | 参考图（eg_ui.md）做法 | 融合决策 |
|---|---|---|
| 暖纸色背景、墨色文字 | 真实环境透传 + 玻璃白字 | 采用暖调虚化书房环境 + 白字玻璃；保留"书房/档案馆"气质而非换成冷峻科技风 |
| 左侧 200px 固定侧栏（品牌+文字导航+状态） | 与窗口分离的悬浮竖向玻璃图标轨 | 改为图标轨，品牌字保留在轨道顶部，系统状态收进轨道底部状态钮浮层 |
| 朱砂强调色 + 苔绿成功色 | 界面近无色，仅黑白两实体 | 两色全部保留但降透明度、压使用频次（徽章/角标/状态点/危险操作）；主按钮统一为近黑胶囊 |
| 标题可用衬线 | SF 风格无衬线 | 主字体走无衬线；记忆卡标题允许轻微书卷气处理，等宽元数据 100% 保留（yiA 识别细节） |
| 记忆页与图谱页原本分成两个页面 | 参考图为两块并排玻璃岛 + 独立浮层 | 合并为"记忆图谱"双岛页：左岛文件列表、右岛图谱，hover 双向联动；点击文件/节点后四周模糊压暗，正中浮出聚焦阅读窗 |
| 对话左右气泡 | 无底色文字 + 玻璃材质 | 用户消息保留实体气泡（改用近黑），助手回复无气泡落在玻璃上 |
| 索引卡微倾角 | 参考图极度规整 | 保留 ≤0.3° 微倾角与 hover 回正，作为产品个性，幅度克制 |
| 新建/发送等按钮 | 玻璃药丸 + 单一实心深钮 | 每个视图只保留一个实心深色主按钮，其余全部玻璃药丸 |
| 浏览器 confirm 二次确认 | 空间里漂浮的小玻璃窗 | 统一为玻璃模态小窗，危险确认才用实心暖红 |
| 默认滚动条 | 窗口外侧白色胶囊滚动条 | 自定义白色细胶囊滚动条 |

## 给 yiA 开发者的备注（不需要投喂给工具）

- 本规格对应 M6 Web MVP：HTTP + SSE 实现，数据源即 runtime/ 现有文件（L2 条目 frontmatter、jobs.json、wechat.json），无新增后端模型。
- 对话页 SSE 对接 chat-cli 同款无头会话；ContextPack 折叠条数据来自 src/memory/context-pack.ts。
- 记忆图谱页右岛的图谱 M7 才做真实渲染（Cytoscape），原型阶段工具自选方案；玻璃背景下节点/连线配色按本规格用白与朱砂；左岛文件行与右岛节点的联动、聚焦阅读层在原型期用前端数据实现即可。
- 环境背景图建议选暖调书房照片 + CSS blur(24px) 自预处理，避免 backdrop-filter 性能压力；玻璃效果在 Chromium 内核验收。
- 原型确认后，将本文件与最终原型一并入库 docs/ 归档。
