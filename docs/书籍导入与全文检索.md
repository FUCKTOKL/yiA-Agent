# 书籍导入与全文检索（第一版）

## 使用方式

打开网页的「书籍」页，点「＋ 导入」，选择文字版 PDF、EPUB、TXT 或 Markdown。
导入完成后，书籍出现在左侧书架；点击书名在右侧读原文，按「上一段／下一段」翻阅。
「下载原文件」取回 yiA 保存的原件副本，不会改动上传前的文件。

检索框输入原文关键词，范围可选全部书籍或某一本书。多个词用空格分隔，要求在同一片段内全部命中。
这是中英文关键词全文检索，不是语义向量检索；没有命中时，可换词或把多个概念分开检索。
点击结果打开对应原文，不仅显示摘要。书中 HTML、JavaScript、链接等不会在阅读区执行。

升级后重启已运行的 Web 服务；已打开的 TUI 用 `/reload` 重新加载扩展。微信 CLI 下次请求加载新工具。
在 Web、微信或 TUI 对话里，可以说「在我导入的某本书里查一下目标设定」。模型使用：

- `list_books`：按书名或作者找书和编号；最多显示 30 本，可缩小关键词。
- `search_books`：按关键词查书，默认最多 5 段，可限定一本书；每次最多 10 段。
- `read_book_passage`：读取命中原文与前后各一段，核对上下文。

回答须注明书名、原文位置，以及 `bk_完整编号:片段号`。网页中点击这种引用可以直接打开原文。
PDF 的「第 N 页」是文件页序，不保证与书中印刷页码相同；EPUB 没有固定页码，用阅读顺序、原文标题和文件路径定位。
TXT/Markdown 用原文行号定位。片段之间有少量重叠，便于保留上下文。

## 支持范围与限制

- 单本原文件最多 50 MiB；提取后的正文最多约 500 万字符；PDF 最多 2000 页，EPUB 最多 2000 个正文文档。
- PDF 先支持可提取文字的版本，不包括 OCR。完全无文字的扫描件会拒绝；少文字或空白页面会提示覆盖范围，不能据此声称整本图中文字已收录。
- PDF 需要打开密码时，提示在本机解密后再导入；不收集或存储密码。
- EPUB 按 spine 阅读顺序导入，并收录未列入 spine 的正文 HTML；忽略导航和脚本。支持普通 EPUB，不保证能读取 DRM 保护的文件。
- TXT/Markdown 支持 UTF-8、带 BOM 的 UTF-16，以及 UTF-8 解码失败后的 GB18030 回退；原文件副本按字节保留。
- 原文件 SHA-256 去重；相同内容换文件名再传也只保留一份，保留首次导入的元数据。
- 不自动生成摘要、不自动把整本书塞进 L2、不做向量检索、不下载远程正文、不解析嵌入式附件。
- 同一服务进程一次只导入一本。解析在独立 Node 子进程中运行，堆上限 384 MB，字体/源文件等仍有额外内存开销；两分钟超时终止。若超时发生在提交边界，请先刷新书架确认结果，再重试。

## 数据与隐私

数据在仓库根的 `runtime/books/library.db`，与 L1/L2/L3 独立。原文件 BLOB、元数据、原文片段和 FTS5 索引由同一个 SQLite 事务写入。
这不是可以随手删掉重建的缓存：原文件副本也在这个数据库里。损坏时返回可读错误，不覆盖原数据。

导入、网页搜索和原文阅读不调用在线模型。只有用户在对话里查书时，工具返回的命中片段/前后文才会发给所选模型，并随会话记录保存。
原文被标记为参考资料，不是可执行指令；提示词要求模型不按书内文字调用工具或泄露本地信息。
日志只记录书籍 id、格式、大小、耗时和状态，不记录书名、检索词或原文。书籍 API 校验本机 Host/端口、Origin、请求类型和上传大小。

删除需网页确认，只删除指定书籍的 yiA 副本、原文片段及关联索引，不改动上传前的源文件。
删除不抹掉已经写入的聊天记录、另存的读书笔记或备份，也不承诺磁盘级安全擦除。
备份前暂停导入和相关会话，备份整个 `runtime/books/`（包括可能存在的 `-wal` / `-shm` 文件），不要只拷贝正在写入的 `library.db`。

本机待导入的 `book/` 目录和运行数据均被 Git 忽略，不随应用源码分发。

## 实现入口

- `yiA/src/books/store.ts`：SQLite、切片、中文二元组/单字与英文分词、BM25 排序、原件和删除。
- `yiA/src/books/parse.ts`：PDF.js、ZIP/XHTML 解析；EPUB 不落地解压，限制解压体积并验证大小/CRC。
- `yiA/src/books/import.ts` / `import-worker.ts`：一次性解析子进程、并发限制、超时、故障隔离；不传递模型密钥。
- `yiA/src/server/book-routes.ts`：挂到既有 `createYiaServer`，没有第二个 Web 服务实现。
- `yiA/src/agent/book-tools.ts`：只读工具，延迟打开数据库，会话关闭时释放连接。
- `yiA/web/js/books.js` / `css/books.css`：书架、搜索、原文、下载/删除、手机布局；复用既有材质和弹窗键盘行为。

接口：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/books` | 书架元数据，不含原件 BLOB |
| POST | `/api/books/import?name=文件名` | `application/octet-stream` 原始二进制；201 新导入、200 已存在 |
| GET | `/api/books/search?q=关键词&bookId=可选编号` | 关键词命中，最多 20 段 |
| GET | `/api/books/:id/passages/:n` | 指定原文与书籍元数据 |
| GET | `/api/books/:id/original` | 原件附件下载，禁止按 HTML 嗅探执行 |
| DELETE | `/api/books/:id` | 按编号事务删除原件、正文、索引 |

运行环境 Node ≥22.13，不需要额外安装 Python、OCR 程序或外部数据库。

## 验证记录

自动测试覆盖 TXT 编码、中文单字/多词、EPUB 阅读顺序/实体/脚本、PDF 页码/密码/无文字、损坏文件、路径越界、ZIP 膨胀、体积上限、事务回滚、并发去重、跨连接即时可见、级联清索引、数据库损坏、HTTP 全链、跨站防护、只读查书工具。

WSL/Node 22.23 上，用用户提供的 418 页 PDF 在临时目录验证：308870 字符、421 片段，解析建索引约 5.4 秒；HTTP 导入、中文查找、原件字节校验与读取工具通过。
未把该 PDF 提交到仓库，也未自动导入用户的正式书架。

浏览器验证导入、重复导入、坏文件提示、按书/跨书检索、翻段、文本安全、引用跳转、删除与刷新、过期请求保护；五页在明暗主题、1440/1024/390/320 宽度下无页面或导航横向溢出。
